# 新手指引与首次进入工作区

官方快速上手从创建组织和默认空间开始，接着连接机器、创建 Agent、建立任务并指派。软件研发与项目管理默认选择需求和缺陷，其他工作类型默认选择通用任务。软件研发的第一个 Agent 默认做代码开发，其他工作类型默认做日常办公。[快速上手](https://help.hifox.com/docs/quickstart) · [空间与工作类型](https://help.hifox.com/docs/space/spaces)

HiFox Windows 0.4.538 的侧栏展开后显示四项。选择「查看全部」进入完整向导，共六组、36 项、560 分。每项有说明和行动入口。界面显示当前名次，点名次徽章未观察到独立榜单。本节的名称、顺序和分值来自本机只读观察。完成条件描述 ShipForge 使用的业务事件，其中需要真实租户才能比对的条件列在文末。

## Windows 使用

首次打开新的 ShipForge 本机工作区会询问组织名称、地址标识和工作类型。完成后进入设置向导。关闭首次设置可从向导继续。已有项目升级时保留记录和当前配置，向导从可恢复的历史操作计算进度。连接团队服务后，桌面与 CLI 使用同一核心记录成员进度。

侧栏显示连接机器、创建第一个 Agent、创建第一个任务、指派给 Agent。展开项可直接进入相应操作。可以隐藏侧栏向导，再从设置里的「开始使用」恢复。阅读说明、查看榜分、切换显示均不会增加积分。分数和显示状态按组织及成员保存，同一组织的各空间共享进度。分数相同的成员同名次。指派任务完成向导步骤，任务仍遵循自己的状态流转。

## 逐项完成条件

在「成员」里可以生成指定邮箱的邀请或通用邀请。管理员把生成的链接交给收件人，收件人连接同一团队服务后使用「接受邀请」，也可通过安装版的系统链接打开确认窗口。通用邀请可邀成员和访客，指定邮箱邀请还可邀管理员。指定邮箱邀请默认七天有效。复制已停用的通用邀请会启用新链接，原链接继续失效。当前的指定邮箱流程采用管理员转交链接，真实邮件投递待联调。[成员与邀请](https://help.hifox.com/docs/space/members)

## 可复验的边界

分数随成功的业务事务写入。失败、预览和同一成员重做步骤都不会重复计分。成员无法替其他成员填写分数。升级可以从创建和编辑事件回补记录，也能恢复后来删除的任务所获得的分数。旧版本未记录的连接验证回执等行为，需要在升级后实际执行一次才能确认。

原版现用组织仅作只读核对。跨账号名次、真实邀请接收、成员被指派后的另一端通知、第三方租户事件送达和积分归属均待独立测试组织联调。官方登录的邮箱验证码、微信扫码和自托管身份流分别记录。原版远端计分算法以实际联调结果为准。

操作协议和功能验收条目见[CLI 手册](cli.md)与[行为覆盖清单](parity-inventory.md)。
