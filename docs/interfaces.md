# 实机界面索引

核对环境为 HiFox 0.4.538、Windows 和一个已登录的示例空间。以下 31 条记录包括页面、抽屉、未启用状态和表单。界面编号也用于随调研交付的本地图库。原始图片含账号与机器标识，公开仓库提供界面记录及厂商公开图例。[功能清单](features.md) · [客户端分析](client-analysis.md)

## 从哪里进入

- **处理任务**　首页 → 空间任务 → 状态列 → 卡片 → 详情。个人工作从“我的任务”进入，点仪表盘切换到这批任务的统计。
- **做计划**　空间任务侧栏 → 迭代、视图或更多模块。新建视图能在保存前预览结果；当前空间的分拣台提供启用说明。
- **派给 Agent**　空间 Agents 或成员目录 → Agent 卡片 → 设置与运行历史。机器详情另有入口；从任务详情也能发起指派。
- **追踪结果**　个人收件箱定位待处理动态，独立对话承载会话，文档库存放个人或团队资料。空间自动化管理规则和触发器。
- **管理组织**　设置侧栏 → 机器、小队、任务状态、外部集成、导入/导出等。部分菜单的可用性与账号和空间配置有关。[官方帮助目录](https://help.hifox.com/docs/welcome)

## 需要另设环境验证的界面

本次核对覆盖空间导航、表单和已有示例任务。真实多人权限变更、跨设备接续、运行中的 Agent 流、历史文档恢复、第三方授权后的同步冲突、开启分拣后的审核与移动端布局，采用官方行为说明；要验证完整交互，需配有测试成员、运行和外部测试库的独立空间。后续按[架构的交付场景](architecture.md)逐项验收。

GPUI 复现时优先保留进入与返回路径、同一任务在不同视图中的身份、空态动作和表单校验。实际字体、图标与色值由 ShipForge 自己的视觉实现决定。
