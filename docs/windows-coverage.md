# Windows 0.11.0 功能对照

此表用于从参考产品的验收目标找到 ShipForge 中的实际入口。单机使用独立 SQLite 工作区，连接团队后由服务端校验角色与对象可见性。桌面与 CLI 使用同一组业务操作。[参考功能清单](features.md) · [参考界面目录](interfaces.md) · [Windows 使用指南](windows.md)

0.11.0 增加邮箱注册、双端登录验证和永久注销，扩展了技能市场、小队共享工作目录、对话指令和工单连接器。专项时间线、跨空间收件箱和 Agent 授权沿用已有验收。详细盘点列有每项的官方依据、测试证据及产品差异。[完整行为盘点](parity-inventory.md)

| 基线 | 在 Windows 中如何使用 | 交付或验证范围 |
| --- | --- | --- |
| F15–F19 技能与小队共享目录 | 在市场查看条目、安装技能及绑定 Agent，或为小队启用同机任务目录共享。 | 两个独立执行进程在同一任务目录交接文件，其他任务使用新目录；验证了团队发布和升级后旧运行的技能内容。[技能与共享目录](skills-market.md) |
| F05、F10、F12 会话与文档 | 在会话中选择 Slash 命令，用任务快捷指令提交审阅，从分享的消息生成图片，按当前权限打开文档链接。 | 文字分享延续旧格式，文件可从原有快照读取。审阅和任务完成各有独立操作。[会话指令](conversation-commands.md) |
| F22 Linear、ClickUp 与 ONES | 配置授权后选择团队、清单或项目，预览并应用变更；可按连接管理同步。 | 本机网络夹具覆盖三家正式 API 的请求与回执，另列需要生产租户核对的权限和事件。[三方连接器](cloud-trackers.md) |
| F01、F14 邮箱和账号生命周期 | 从「设置 → 账号列表」注册、登录、维护个人资料和预览注销影响。 | 临时邮箱网关、团队服务和 Windows 原生窗口覆盖邮箱与设备配对、编辑资料、共享机器限制、组织清理、其他设备失效及同邮箱新身份。[账号与邮箱](account-lifecycle.md) |
| F06–F11 专项计划、分拣与个人收件箱 | 在专项查看排期，按空间规则分拣任务，个人收件箱按当前分区和空间处理提醒。 | 分拣责任关联到指定成员，桌面和收件箱可分别按事件静音。[通知操作](inbox.md) |
| F15–F18 Agent 与小队 | 在 Agent 目录管理可见性、分身与归档，从小队安排专属成员。 | 通过不同身份验证目录、继承、归档取消及历史读取。[行为盘点](parity-inventory.md) |
| F22 禅道与 PingCode | 在连接器详情配置凭据及项目并预览待导入的数据。 | 导入和回写按产品或项目绑定，真实供应商租户另列待验。[工单接入](tracker-integrations.md) |
| F01、F14 多账号与个人令牌 | 在左栏打开账号列表切换身份。设置中的个人访问令牌可选择 30 天、90 天、一年或永久。 | Windows 原生窗口覆盖从旧位置进入、切换账号、签发、吊销、当前身份失效后重新认证。两个实际 CLI 身份验证权限回退、机器关联及单账号文件升级。[Windows 验收](design-qa.md) |
| F03、F06、F10 类型、视图与讨论 | 切换任务类型前检查有值字段与目标工作流。把筛选另存为个人或共享视图，在任务评论中解决或重新打开一串讨论。 | 通过原生窗口和多身份团队服务验证损失确认、分享链接的读取权限和讨论状态。具体字段与入口见 CLI 手册。[协作操作](cli.md) |
| F12 对话置顶、分叉与转任务 | 可在个人列表隐藏对话，从用户消息或 Agent 回复建立分支；直接对话支持选择已有任务或请执行者创建新任务。 | 独立本地客户端和外部进程验证个人列表、前缀上下文、任务关系和重复提交。官方生产模型与真实账号的交付另行联调。[对话说明](conversations.md) |
| F22 第三方工单 | Bugly 通过提单接口送入任务，Zoho BugTracker 从门户与项目导入，TAPD 按项目导入需求及缺陷。 | 使用隔离 HTTP 上游和真实进程核对签名、两种 TAPD 身份、分页限流、凭据轮换、来源去重和批次回滚。各平台的生产权限与待联调条件见专页。[工单接入](tracker-integrations.md) |
| F01 空间生命周期与个人导航 | 在空间目录加入公开空间、固定入口。在空间设置切换分拣台和客户请求，或预览停用空间时未完成任务的处理方式。 | 两种成员身份和 Windows 原生窗口覆盖临时入口、个人固定、停用期间只读、撤销机器租约及恢复编辑。受迁移限制的任务会使整批迁移回滚。[空间操作](space-lifecycle.md) |
| F03 标签 | 从任务的标签选择器搜索或直接创建，或在任务页批量增删、替换标签及清除分组。设置中可管理颜色、分组、归档和合并。 | 同组互斥，多标签按交集筛选。合并会更新任务和已保存视图，组织标签随任务跨空间保留。旧工作区升级保留任务修订和操作者的积分。[官方行为](https://help.hifox.com/docs/task/task-labels) |
| F07 自动与手动迭代 | 在迭代设置中选择周期、时区、冷却和自动加入条件。手动模式可并行启动多期，按负责人筛选。 | 已验证跨夏令时顺延、停用后的历史、服务重启后在首个客户端读取前自动结项。[日期和配置](iterations.md) |
| F22 Jira 客户端和 Slack 卡片 | Jira 客户端使用团队服务地址和个人令牌。已配置的 Slack 话题可以通过人员选择器改派任务。 | 原版 jira-python 3.10.5 客户端在隔离服务上完成查询、增删改、评论和状态流转。Slack 测试验证真实卡片格式、签名回调、权限、重放，以及保留 Agent。Slack 生产租户送达待联调。[Jira 接入](jira-api.md) · [消息平台配置](../crates/shipforge-core/PROVIDERS.md) |
| F27 初次设置与新手指引 | 初次进入设置组织和默认空间，从侧栏展开四个行动，选择「查看全部」打开六组设置。 | Windows 隐藏原生窗口校验首次设置、36 项按钮和隐藏/恢复。逐项通过公开业务操作获得全部 560 分；重开、升级和成员隔离均有回归。[完成条件与取证](onboarding.md) |
| F01 团队邀请 | 在「成员」选择邮箱邀请或邀请链接，同时选择要加入的空间。已有团队身份可在桌面确认加入。 | 邮箱必须匹配登录身份，共享链接可邀成员或访客。隔离 HTTP 服务覆盖只读权限、旧链接撤销、重复接受和已有成员额外加入私有空间。真实邮件投递待联调。 |
| F02 多人处理 | 空间设置开启「允许多个处理人」，任务可同时选多名人员及独立的 Agent 或小队。 | 按处理人筛选覆盖全部人员，分组可出现多张卡片，汇总按任务计数。取消开关保留已存历史多人数据。 |
| F12 群聊、私有对话与片段分享 | 在对话详情管理成员与群主，设置免打扰、清理本人的历史，或按选区创建可撤回的分享。 | 独立身份验证邀请接受、移除后的权限、提及提醒、冻结分享时的正文以及撤回。[会话操作](conversations.md) |
| F14 个人偏好和快捷键 | 在设置中切换主题、外边框、语言和消息发送组合，录制或恢复命令快捷键。 | Windows 原生控件验证冲突拒绝、输入法组合态、实际发送和换行；偏好按成员持久化。[个人设置](personal-settings.md) |
| F22 外部话题与代码回链 | 从任务选择 Slack 话题回复，或在 GitHub、GitLab 连接器中开启按任务编号关联提交和合并请求。 | 隔离服务验证签名、事件重送、撤销授权、外仓隔离、显式话题回写及审查规则入队。真实租户 OAuth、完整操作卡片及企业自建网络仍待联调。 |
| F01 组织与空间 | 设置内建立组织、空间、成员，在团队服务为成员签发相应作用域的令牌。 | 组织与空间角色分别校验。双客户端测试覆盖只读、写入、撤销令牌和离线缓存。 |
| F02–F04 任务和关联 | 看板创建任务，在详情编辑标题、描述、处理人和负责人；设置管理任务类型、自定义字段、状态与关系类型。 | 任务编号稳定，状态可改名。父子、阻塞、相关、重复项保留双方关联，类型可限制字段与状态。 |
| F05–F06 个人与空间视图 | 「我的任务」与空间任务提供筛选、看板、列表、表格、仪表盘和保存为视图。 | 保存依据查询条件计算结果，任务变化后可刷新。原生演示与正式工作区共用渲染。 |
| F07–F09 迭代、专项和分拣 | 左栏进入迭代、专项或分拣台。迭代时间轴展示阶段、任务容量和完成量。结项先预览剩余事项，选择转入下一期或待规划。 | 专项按参与空间权限汇总，移动迭代保持专项归属。访客和外部来源可按配置先分拣。 |
| F10–F11 评论与通知 | 任务详情发表评论或关注任务。收件箱打开关联事项，并按接收人处理提醒。 | 核心验证回复、提及、关注及同事项通知聚合。 |
| F12–F13 对话、文档、附件 | 在对话中发送消息，查看运行产物，保存到文档库。文档可设置个人或团队可见，查看或恢复历史版本。 | 真实文件按对象权限读写，单文件 4 MiB。CLI 或桌面均可上传下载，下载时验证 SHA-256。 |
| F14 桌面导航 | 原生标题栏提供前进、后退、刷新和全局搜索；侧栏切换当前空间的对象和设置。 | 本次交付 Windows x64。参考资料中的手机客户端独立于 Windows 版本。 |
| F15–F17 Agent、小队和技能 | 创建 Agent、配置分身和执行机器，组成小队，或从内置市场安装模板和技能。 | 分身逐字段继承，运行保留配置快照。小队的子运行和最终汇总可追踪。市场包含随版本提供的模板。 |
| F18–F20 执行机器和目录 | 登记机器，选择已批准的外部程序与工作目录，指派任务并查看结果、回复或取消。 | Windows 测试启动真实子进程，同时创建同仓库的两个隔离 Git worktree，并验证同一直接目录串行执行。外部模型账号和订阅由机器操作者配置。 |
| F21 自动化 | 在空间配置规则、执行者、触发条件和通知收件人。可选状态、评论、Webhook、固定间隔及带 IANA 时区的每日或每周时间计划。 | Worker 扫描到期计划。测试覆盖跨日、夏令时、停机后补发、重启去重以及绑定到单条规则的回调权限。 |
| F22 集成 | 配置四种工单来源（GitLab、Jira、Linear、Asana）和七种消息来源（飞书、Slack、Telegram、Teams、Discord、企业微信、钉钉）。GitHub Issues 另有按仓库或单条拉取与显式回写。 | 十一种格式由代表性事件验证预览、落单和重复投递。GitHub 公共 Issue 已实际读取，写回使用隔离服务测试。各平台的认证、订阅和中继要求见[入站覆盖表](../crates/shipforge-core/PROVIDERS.md)。 |
| F23 导入导出 | 设置内导出空间数据，或预览字段映射与将被导入的记录，再提交导入。 | 事务校验和稳定外部 ID 支持重放。完整服务器恢复使用停止服务后的数据目录备份。 |
| F24 CLI 与部署 | 包含原生桌面、CLI、团队服务和机器执行端。安装版与便携 ZIP 同时提供。 | 包验证覆盖安装、Unicode 路径、复装后数据、协议 schema、双客户端和限权 Webhook。 |
| F25 可视化 Workflow | 使用空间自动化配置可执行规则。 | 节点连线编辑器仍属于参考产品官网预告的后续方向。 |
| F26 工具、知识与 MCP | 在 Agent 上配置可用工具。机器单独批准 MCP 程序、工具名与固定参数。 | 权限与当前运行租约均参与调用校验，运行记录保留工具结果；Windows 测试覆盖真实 stdio MCP 子进程。 |
