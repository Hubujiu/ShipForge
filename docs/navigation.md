# 工作区搜索、成员目录与实时协作

标题栏的搜索框和个人设置中的命令菜单快捷键均可进入搜索。输入对象标题、编号、正文片段或标签名可查找当前组织已加入空间中的记录。结果按对象类型展示，并附空间和标识。选择一项会用当前身份重新读取该对象，然后定位到相应空间。评论会打开所属任务的讨论，聊天消息会打开所属对话。也可以直接按名称查找导航和新建命令。[HiFox 空间](https://help.hifox.com/docs/space/spaces)

左侧「成员」按 Agent、小队、真人及机器分类，支持按名称或标识检索。同名成员旁显示空间与账号标识。选择真人后可在详情中打开私聊。首页的「快捷新建」可以建任务、选择 Agent、小队或真人对话，也可以选择人员与 Agent 创建群聊。私聊的双方从同一空间打开时会进入同一条记录。建群时若有一个对象无效，此次创建会全部撤回。[HiFox 成员与群聊更新](https://help.hifox.com/changelog/2026-11-13)

团队窗口约每五秒重新读取当前视图。两端同时打开同一对话时，新消息会自动出现。连接断开时侧栏显示离线，受保护对话的内容从窗口移除。恢复连接后，若用户仍停在原位置，窗口会重新校验权限并恢复对话及期间的消息。成员被移出空间后，界面清理旧抽屉、搜索和导航记录，并选中仍可访问的空间。

| CLI 请求 | 作用 |
| --- | --- |
| `{"op":"search","space":"default","query":"发布","search_scope":"organization"}` | 在本组织可访问的空间中搜索。省略 `search_scope` 时只搜索当前空间。 |
| `{"op":"directory.people","space":"default","kind":"member","query":"李"}` | 查找真人。可选类别还有 `agent`、`crew` 和 `machine`。 |
| `{"op":"chat.start","space":"default","mode":"member","target":"lee","request_id":"open-lee-1"}` | 打开双方的私聊。使用 `agent` 或 `crew` 模式可以开始新的 Agent 或小队对话。 |
| `{"op":"chat.start","space":"default","mode":"group","title":"交付评审","members":["lee"],"agents":[],"request_id":"group-1"}` | 在一次事务中创建群组并加入选中的对象。 |

## 组织默认设置

在设置中打开「组织」可调整组织的内容语言和任务优先级。新空间会按组织默认语言创建任务类型与初始状态，邮箱邀请记录也保存创建时的语言。成员仍可独立选择自己的界面语言，已有空间中命名过的类型和状态会保留原名。

四档包括紧急、高、中和低。五档额外提供最低，两种模式均可选择无优先级。导入明确标记为最低的任务或通过 Jira API 写入 Lowest 时，会在同一事务中将组织切到五档。导入预览会回滚此更改。切回四档后，原有任务仍保留最低值，新增任务只能选择当前四档。历史记录中的无优先级保持原值。[HiFox Jira 帮助](https://help.hifox.com/docs/integration/jira)

当前组织的管理员可以保存默认设置，普通成员可输入组织名称退出。组织所有者可以输入名称删除组织和所属空间，提交时还会比对成员数。删除操作会保留其他组织。本机和团队服务的内置 `default` 是引导空间，删除入口适用于用户新建的组织。

组织可以有多位所有者。在设置的「组织」页中，当前所有者可添加另一位所有者、将选定所有者改为管理员，或将自己的管理权转让给组织成员。最后一位所有者须先指定继任者才能退出。拥有子空间的成员可在空间列表选择「转让空间管理权」，将空间交给已参加该空间的成员。两类转让都会在提交时复核成员和修订号。账户注销时，仍有其他所有者的组织会继续保留。[HiFox 成员与角色](https://help.hifox.com/docs/space/members)
