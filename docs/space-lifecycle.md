# 空间、历史与个人侧栏

点击左侧空间名称进入空间目录。「使用中」显示当前身份可发现的空间。组织成员可以加入公开空间，成为成员后可进入任务和文档等内容。私有空间成员和访客通过邀请或管理员分配加入。组织管理员能查看并管理空间元数据，访问任务和文档仍取决于空间成员身份。空间创建者保留成员身份。

从目录点「退出空间」会撤销自己的空间访问权限和任务指派。已退出的成员可以重新加入仍公开的空间。每个空间独立保存个人侧栏。研发空间默认固定已启用的迭代和视图，其他工作类型默认固定视图和专项。在「更多」中可打开、固定或取消固定功能；打开未固定的功能时，当前入口暂时出现在侧栏，离开后消失。原有空间缺少工作类型时沿用研发空间的默认入口。

分拣台与客户请求默认关闭，迭代沿用已有空间的配置。在空间设置中可以调整模块。「更多」会向有权限的管理员提供启用入口。已启用的客户请求支持新建、查看和修改标题、说明、联系人及处理状态。关闭客户请求模块保留已有记录，再次启用后可继续处理。

管理员在目录选择「停用空间」后可看到未完成任务数。可以取消这些任务，或将其一次性移动至同组织的另一个可写空间。迁移保留所有可迁移的任务历史，目标空间的类型、状态和权限须兼容。带有执行历史、外部来源或仍有关联的任务须先按单项迁移规则处理，任何一项失败会撤回整批变更。待执行、执行中和等待输入的工作随停用停止。

在「已停用」中选择「查看历史」可继续阅读当时拥有权限的内容。空间数据只读。「恢复空间」会重新开放写入，同时保留之前的任务状态、历史和侧栏设置。[HiFox 空间帮助](https://help.hifox.com/docs/space/spaces) · [CLI 操作](cli.md)
